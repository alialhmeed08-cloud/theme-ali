# PhoneX — قالب سلة Twilight

قالب داكن فاخر متخصص في متاجر الجوالات والإكسسوارات، مبني على محرك Twilight الرسمي.

## المزايا
- ثيم داكن احترافي مع ألوان قابلة للتخصيص من لوحة التحكم
- 8 مكونات رئيسية قابلة للتعديل (هيرو، ماركات، تصنيفات، منتجات، عرض اليوم بعدّاد، ثقة، آراء، نشرة)
- مكونات سلة الرسمية: البحث، السلة، الفلاتر، خيارات المنتج، التقسيط، الشراء السريع
- متجاوب بالكامل + شريط تنقل سفلي للجوال
- ترجمات عربي / إنجليزي

## الرفع والنشر
1. أنشئ مستودع GitHub جديد وارفع ملفات هذا القالب كما هي (twilight.json في الجذر).
2. من Salla Partners Portal: My Themes → Import Theme → اختر المستودع.
3. عاين وطوّر عبر Salla CLI أو من صفحة التطوير في البوابة.
4. قدّم القالب للمراجعة (UI/UX ثم Technical ثم Metadata) قبل النشر في السوق.

## البنية
- twilight.json → إعدادات القالب والمكونات والـ features
- src/views/layouts → master.twig
- src/views/pages → الرئيسية، قائمة المنتجات، صفحة المنتج، السلة
- src/views/components → الهيدر، الفوتر، مكونات الرئيسية الثمانية
- src/assets → CSS و JS
- src/locales → ar.json / en.json
